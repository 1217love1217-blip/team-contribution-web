
>>프롬포트 v1
팀플 기여도 및 일정 관리 시스템을 파이썬으로 만들어 줘. 
팀원별 태스크와 마감일, 진행률을 입력받아서 기여도를 분석해서 보여 주면 돼.



>>프롬포트 v2(5요소)
당신은 프로그래밍을 처음 배우는 대학생을 가르치는 파이썬 강사입니다.
아래는 제가 만들려는 시스템의 목적 정의서입니다.

[시스템 이름] 팀플 기여도 & 일정 관리 시스템 (v2.0)
[1. 문제] 
- 단톡방에 팀플 일정이 파편화되어 마감일 지연 빈번.
- 수치화된 기여도 부재로 업무 쏠림 및 무임승차 발생.
[2. 사용자] 
- 학기 중 팀플(2~4주) 동안 주 2~3회, 3분 이내로 접속해 진척도를 업데이트하는 대학생.
[3. 해결] 
- 팀원, 태스크, 마감일, 진행률을 등록/관리하고 마감 임박(D-3) 및 지연(Overdue) 경고.
- 팀 전체 진행률을 ASCII 막대그래프([████░░░░░░])로 시각화하고 팀원별 기여도 산출.
[4. 데이터] 
- 입력: 팀원명, 태스크명, 마감일(YYYY-MM-DD), 진행률(0~100 정수)
- 저장: data/members.csv, data/tasks.csv (UTF-8)
[5. 성공기준] 
- 에러 입력 시 프로그램 정지 없이 재입력 안내, 1초 이내 표 출력, 최초 실행 시 빈 CSV 자동 생성.

이 시스템을 개발하기 위한 계획을 세워 주세요. 다음 조건을 지켜 주세요.

[제약]
- 파이썬 표준 라이브러리와 pandas, matplotlib 범위 안에서만 설계할 것
- 데이터베이스 대신 CSV 파일을 사용할 것
- 프로그래밍 입문자가 이해할 수 있는 수준으로 설명할 것

[출력 형식]
1) 모듈 구성표: 모듈명 / 역할 / 입력 / 출력
2) 모듈 간 실행 순서
3) 각 모듈에서 초보자가 어려워할 만한 지점과 대비책
4) 불명확한 점이 있다면 코드를 쓰기 전에 먼저 질문해 주세요

>>확정한 모듈 구성표
[팀플 기여도 & 일정 관리 시스템 — 모듈 구성표]

1) 모듈 구성표 (5개)
| 모듈명 | 역할 | 입력 | 출력 |
|---|---|---|---|
| file_handler.py | CSV 파일 자동 생성 및 데이터 읽기/쓰기 | members.csv, tasks.csv | 팀원 및 태스크 데이터 리스트 |
| input_mgr.py | 팀원, 태스크 신규 등록 및 진행률 유효성 검사 | 팀원명, 태스크명, 날짜, 진행률 | 유효성 통과된 업데이트 데이터 |
| analyzer.py | 지연(Overdue)/D-3 태스크 식별 및 개인별 기여도 계산 | 전체 태스크 리스트 | 지연/D-Day 목록, 기여도 지표 |
| viewer.py | 데이터 정렬 조회 및 ASCII 진행바 기반 시각화 | 기여도 지표, 전체 진행률 | 화면 정렬 출력 (표, 막대그래프) |
| main.py | 프로그램 메뉴 출력 및 전체 모듈 실행 순서 제어 | 사용자 메뉴 선택 | 종합 요약 리포트 (team_report.txt) |

2) 실행 순서
main (시작) → file_handler (CSV 로드) → main (메뉴 선택) → input_mgr (정보 입력/진행률 갱신) → analyzer (기여도 및 일정 분석) → viewer (결과 화면 시각화) → file_handler (CSV 최종 저장) → main (종료 및 리포트 내보내기)
